# MediScan AI (医疗扫描 AI)

这是一个关于 **医疗扫描影像分析与辅助诊断** 的 AI 项目（OPC比赛参赛作品）。

## 📝 项目简介
本项目旨在利用深度学习技术，对医疗扫描影像（如 X 光、CT 或 MRI）进行智能分析。通过算法自动识别病灶或异常区域，为医疗诊断提供辅助参考。核心算法代码位于 `bpp.py` 中。

## 🛠️ 环境依赖
项目基于 Python 开发，请确保你的环境中安装了 Python 3.8 及以上版本。

1. 克隆本项目到本地：
   ```bash
   git clone https://github.com/hhhh200728/mediscan-ai.git
   cd mediscan-ai
   pip install -r requirements.txt
   python bpp.py
    ```
