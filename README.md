# MediScan AI (医疗扫描 AI)

这是一个关于 **医疗扫描影像分析与辅助诊断** 的 AI 项目（OPC比赛参赛作品）。

## 📝 项目简介
本项目是一个基于大语言模型（DeepSeek）的医疗影像科智能文本导诊系统。旨在解决患者在影像检查前后的信息不对称与焦虑问题。系统采用本地知识库优先匹配与大模型兜底策略，提供有温度的垂直导诊服务。

## 🛠️ 环境依赖
项目基于 Python 开发，请确保你的环境中安装了 Python 3.8 及以上版本。

1. 克隆本项目到本地：
   ```bash
   git clone https://github.com/hhhh200728/mediscan-ai.git
   cd mediscan-ai
   pip install -r requirements.txt
   streamlit run bpp.py
    ```
